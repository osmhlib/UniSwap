# UniSwap Frontend

Початковий робочий frontend для наявного ASP.NET Core API UniSwap.

## Технології
- React + TypeScript
- Vite
- React Router
- Lucide icons

## Запуск

1. Переконайся, що бекенд запущений на `https://localhost:7258`.
2. У папці `uniswap-frontend` виконай:

```bash
npm install
```

3. Створи `.env` на основі `.env.example`. Якщо API має іншу адресу, зміни `VITE_API_BASE_URL`.
4. Запусти frontend:

```bash
npm run dev
```

5. Відкрий адресу, яку покаже Vite (типово `http://localhost:5173`).

## Важливо для CORS

Перед запуском API дозволь origin фронтенду. У PowerShell:

```powershell
$env:Cors__AllowedOrigins__0 = 'http://localhost:5173'
dotnet run --project UniSwap.WebApi --launch-profile https
```

Якщо HTTPS API не відкривається через сертифікат, у терміналі з .NET SDK виконай:

```powershell
dotnet dev-certs https --trust
```

## Реалізовано у першій версії
- каталог із пошуком, категоріями та фільтром доступності;
- реєстрація, вхід, вихід та завантаження профілю;
- перегляд оголошення, фото та запит резервування;
- створення, редагування, публікація і видалення власних оголошень;
- особистий кабінет;
- перегляд отриманих/надісланих резервувань та обмінів;
- базова панель модерації для Admin.

Категорії у формі є початковим набором для інтерфейсу: бекенд не надає окремого довідника категорій. Значення категорій потрібно узгодити з тими, які використовуються у ваших оголошеннях.
