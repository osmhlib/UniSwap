# UniSwap backend

Навчальний ASP.NET Core API для обміну речами. Рішення розділене на Domain, Application, Infrastructure і WebApi; додатковий консольний проєкт SmokeTests перевіряє прототип.

## Запуск і перевірка

Потрібен .NET SDK 10. Виконайте `dotnet build UniSwap.slnx` та `dotnet run --project UniSwap.SmokeTests/UniSwap.SmokeTests.csproj`. API запускається командою `dotnet run --project UniSwap.WebApi/UniSwap.WebApi.csproj`.

## Поточний стан

Доменна модель містить стани оголошення з технічного завдання, перевірку назви, опису, категорії та стану речі, а також переходи для публікації, резервування, обміну й модерації. Reservation та ExchangeRequest — різні сутності; пропозиція обміну пов’язує два оголошення. Існуючий прототип API підтримує лише створення і публікацію оголошень та створення і прийняття пропозиції обміну. Його контракти змінені: створення оголошення вимагає category і condition, створення пропозиції — offeredListingId, а прийняття — actorId.

**Прототип не готовий до розгортання або підключення фронтенду.** Автентифікація і серверна авторизація ще не реалізовані: ідентифікатори користувачів з HTTP-запитів можна підробити. Зберігання в пам’яті втрачається після зупинки і не гарантує захист від одночасного прийняття конкуруючих запитів. Правила домену не замінюють перевірку особи, транзакції та обмеження бази даних.

Залишається реалізувати PostgreSQL та EF Core з міграціями й захистом від паралельних змін, реєстрацію, вхід, вихід і політики доступу, прикладні сценарії та API для резервувань, повні сценарії оголошень і обміну, профілі, модерацію, пошук, зображення, DTO, контрольовані помилки й інтеграційні перевірки. Поточні димові перевірки не підтверджують відповідність усім критеріям приймання ТЗ.
